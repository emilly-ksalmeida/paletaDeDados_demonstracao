# paleta_de_dados

Aplicação web desenvolvida como parte do Trabalho de Extensão do curso de Análise e Desenvolvimento de Sistemas (ADS).

O projeto tem como objetivo facilitar a visualização e gestão dos dados de alunos de uma escola de artes plásticas, utilizando uma planilha como fonte de dados. A aplicação transforma os dados da planilha em uma interface web mais organizada, permitindo que a secretaria consulte as informações de forma mais prática.

## Objetivo

Desenvolver uma solução simples e acessível para melhorar a visualização dos dados escolares atualmente armazenados em planilhas.

A aplicação busca:

- Facilitar a consulta dos dados dos alunos.
- Organizar as informações em uma interface amigável.
- Reduzir a necessidade de manipulação direta da planilha.
- Permitir a busca e filtragem dos registros.
- Manter a planilha como fonte dos dados, sem a necessidade inicial de um banco de dados.
